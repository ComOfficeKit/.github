# ComOfficeKit

**Word, Excel and PowerPoint files in your own apps, on the device.** ComOfficeKit is the document engine behind [LynxOffice](https://lynxoffice.com), packaged as an SDK: read, edit, save and render `.docx`, `.xlsx` and `.pptx` files in your process, with no Microsoft Office, no LibreOffice and no server.

| Repository | For | Ships as |
|---|---|---|
| [ComOfficeKit-Apple](https://github.com/ComOfficeKit/ComOfficeKit-Apple) | iOS, iPadOS and macOS apps, in Swift | Two binary frameworks, with samples |
| [ComOfficeKit-Windows](https://github.com/ComOfficeKit/ComOfficeKit-Windows) | Windows software, in .NET 8 or later | A NuGet package with the engine inside, with samples |

Each repository's README covers the API, the requirements, the free trial and licensing.
